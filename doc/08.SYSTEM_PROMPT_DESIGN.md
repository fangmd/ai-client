# 系统提示词功能设计方案

## 一、概述

### 1.1 功能目标

系统提示词功能允许用户设置一个全局的系统提示词，该提示词会在所有 AI 聊天请求中自动作为 `system` 消息添加到消息列表的开头。这允许用户自定义 AI 助手的行为、风格和角色。

### 1.2 核心功能点

- **全局系统提示词配置**：在设置页面可以配置系统提示词
- **自动注入**：在所有 AI 请求中自动将系统提示词作为第一条 `system` 消息
- **可选功能**：系统提示词为空时不添加，不影响现有功能
- **持久化存储**：使用 Config 表存储系统提示词配置

### 1.3 技术选型

- **存储**：使用现有的 Config 表（Key-Value 结构）
- **配置键**：`system_prompt`
- **注入位置**：在 AIHandler 中，发送请求前自动注入
- **UI 位置**：设置页面新增系统提示词编辑区域

## 二、数据库设计

### 2.1 数据存储

使用现有的 `Config` 表存储系统提示词，无需修改数据库 Schema。

```prisma
model Config {
  key       String   @id       // 配置键：'system_prompt'
  value     String             // 配置值：系统提示词内容（纯文本）
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@map("config")
}
```

### 2.2 配置项定义

| Key | Default | Description |
|-----|---------|-------------|
| `system_prompt` | `""` (空字符串) | 全局系统提示词，为空时不注入 |

### 5.3 AIHandler 修改

在 `AIHandler` 的 `streamChat` 处理器中，在调用 Provider 之前注入系统提示词：

```typescript
// src/main/handlers/ai-handler.ts
ipcMain.on(IPC_CHANNELS.ai.streamChat, async (event, request: StreamChatRequest) => {
  const { messages, config, requestId, tools, sessionId } = request

  // 获取系统提示词
  const systemPrompt = await getConfigValue<string>('system_prompt', '')
  
  // 如果系统提示词不为空，添加到消息列表开头
  const finalMessages = systemPrompt.trim()
    ? [{ role: 'system', content: systemPrompt.trim() }, ...messages]
    : messages

  // 使用 finalMessages 调用 Provider
  await provider.streamChat(finalMessages, config, callbacks, ...)
})
```

## 七、实现流程

### 7.1 系统提示词注入流程

```
1. 用户发送消息
   ↓
2. useAIChat Hook 准备消息列表
   ↓
3. 发送 IPC: ai:stream-chat
   ↓
4. AIHandler 接收请求
   ↓
5. AIHandler 从 Config 获取系统提示词
   ↓
6. 如果系统提示词不为空，添加到消息列表开头
   ↓
7. 调用 Provider.streamChat(finalMessages, ...)
   ↓
8. Provider 处理请求（包含系统提示词）
```

### 7.2 配置保存流程

```
1. 用户在设置页面编辑系统提示词
   ↓
2. 点击保存按钮
   ↓
3. configStore.setSystemPrompt(prompt)
   ↓
4. IPC: config:set { key: 'system_prompt', value: prompt }
   ↓
5. ConfigHandler 处理请求
   ↓
6. Repository 保存到数据库
   ↓
7. 更新 configStore 状态
```

## 十、注意事项

### 10.1 系统提示词注入时机

- **注入位置**：在 AIHandler 中，调用 Provider 之前注入
- **注入条件**：只有当系统提示词不为空（trim 后）时才注入
- **消息顺序**：系统提示词始终作为第一条 `system` 消息，位于所有用户消息之前

### 10.2 消息列表处理

- **避免重复**：如果消息列表中已经存在 `system` 消息，系统提示词仍然会添加到开头
- **消息格式**：系统提示词作为标准的 `system` 角色消息，格式为 `{ role: 'system', content: systemPrompt }`
- **Provider 兼容性**：所有 Provider 都应该支持 `system` 角色消息

### 10.3 性能考虑

- **缓存优化**：系统提示词在每次请求时从数据库读取，可以考虑在 AIHandler 中缓存（可选优化）
- **读取频率**：每次 AI 请求都会读取一次系统提示词，频率较高但影响较小（Config 表查询很快）

### 10.4 用户体验

- **即时生效**：保存系统提示词后，下次发送消息时立即生效
- **清空功能**：支持将系统提示词设置为空字符串来禁用功能
- **提示信息**：在 UI 中提供清晰的说明，告知用户系统提示词的作用

### 10.5 向后兼容

- **默认行为**：系统提示词默认为空，不影响现有功能
- **可选功能**：用户可以选择不设置系统提示词，功能完全可选
- **数据迁移**：无需数据迁移，新功能直接可用

### 12.2 ConfigStore 扩展

```typescript
// src/renderer/src/stores/configStore.ts
export const useConfigStore = create<ConfigState>((set) => ({
  theme: DEFAULT_CONFIG[CONFIG_KEYS.THEME],
  systemPrompt: DEFAULT_CONFIG[CONFIG_KEYS.SYSTEM_PROMPT],

  loadConfig: async () => {
    // ... 现有代码 ...
    // 解析系统提示词配置
    if (configs[CONFIG_KEYS.SYSTEM_PROMPT] !== undefined) {
      set({ systemPrompt: configs[CONFIG_KEYS.SYSTEM_PROMPT] })
    }
  },

  setSystemPrompt: async (prompt: string) => {
    try {
      const response = (await window.electron.ipcRenderer.invoke(IPC_CHANNELS.config.set, {
        key: CONFIG_KEYS.SYSTEM_PROMPT,
        value: prompt
      })) as IPCResponse<ConfigItem>

      if (response.code === SUCCESS_CODE) {
        set({ systemPrompt: prompt })
      }
    } catch (error) {
      console.error('Failed to set system prompt:', error)
    }
  }
}))
```

### 12.3 SystemPromptSettings 组件

```tsx
// src/renderer/src/components/SystemPromptSettings.tsx
import React, { useState, useEffect } from 'react'
import { Button } from '@renderer/components/ui/button'
import { Textarea } from '@renderer/components/ui/textarea'
import { useConfigStore } from '@renderer/stores/configStore'
import { Save, Loader2 } from 'lucide-react'

export const SystemPromptSettings: React.FC = () => {
  const { systemPrompt, setSystemPrompt } = useConfigStore()
  const [localPrompt, setLocalPrompt] = useState(systemPrompt)
  const [saving, setSaving] = useState(false)
  const [saved, setSaved] = useState(false)

  // 当 store 中的 systemPrompt 变化时，同步到本地状态
  useEffect(() => {
    setLocalPrompt(systemPrompt)
  }, [systemPrompt])

  // 处理保存
  const handleSave = async () => {
    setSaving(true)
    setSaved(false)
    try {
      await setSystemPrompt(localPrompt)
      setSaved(true)
      setTimeout(() => setSaved(false), 2000)
    } catch (error) {
      console.error('Failed to save system prompt:', error)
      alert('保存失败，请重试')
    } finally {
      setSaving(false)
    }
  }

  const hasChanges = localPrompt !== systemPrompt

  return (
    <section className="mb-8">
      <h2 className="text-lg font-medium mb-4">AI 设置</h2>
      <div className="rounded-lg border bg-card p-4">
        <div className="mb-3">
          <span className="text-sm font-medium">系统提示词</span>
          <p className="text-sm text-muted-foreground mt-1">
            设置全局系统提示词，将应用于所有 AI 对话。留空则禁用此功能。
          </p>
        </div>
        <Textarea
          value={localPrompt}
          onChange={(e) => setLocalPrompt(e.target.value)}
          placeholder="例如：你是一个专业的编程助手，擅长解释代码和解决技术问题。请用简洁明了的方式回答问题。"
          rows={6}
          className="mb-3 font-mono text-sm"
        />
        <div className="flex items-center justify-between">
          <div className="text-sm text-muted-foreground">
            {hasChanges && <span className="text-orange-500">有未保存的更改</span>}
            {saved && <span className="text-green-500">保存成功</span>}
          </div>
          <Button onClick={handleSave} disabled={saving || !hasChanges} size="sm">
            {saving ? (
              <>
                <Loader2 className="size-4 mr-2 animate-spin" />
                保存中...
              </>
            ) : (
              <>
                <Save className="size-4 mr-2" />
                保存
              </>
            )}
          </Button>
        </div>
      </div>
    </section>
  )
}
```
