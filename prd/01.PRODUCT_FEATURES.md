# 产品功能文档

本文档从产品功能角度整理项目的功能范围和实现状态，包括已实现功能和后续规划。

## 一、产品概述

AI 聊天客户端是一个基于 Electron 的桌面应用，提供与 AI 模型对话的能力。支持多 AI 提供商、会话管理、文件上传、工具调用等功能。

### 核心价值

- **多 AI 提供商支持**: 支持 OpenAI、Anthropic 等多种 AI 提供商
- **流畅的对话体验**: 实时流式响应，快速获得 AI 回复
- **完整的会话管理**: 保存和管理所有对话历史
- **丰富的交互方式**: 支持文本、图片、工具调用等多种交互方式

## 二、核心功能

### 2.1 AI 对话

#### 2.1.1 基础对话功能 ✅

- **实时对话**: 支持与 AI 进行实时对话，AI 回复以流式方式实时显示
- **多行输入**: 支持多行文本输入，Enter 发送，Shift+Enter 换行
- **消息状态**: 显示消息发送状态（发送中、已完成、错误）
- **请求取消**: 支持中断正在进行的 AI 请求
- **错误处理**: 完善的错误提示和处理机制

#### 2.1.2 消息显示 ✅

- **Markdown 渲染**: 支持 Markdown 格式的消息内容渲染
- **代码高亮**: 代码块支持语法高亮显示
- **消息时间**: 显示每条消息的创建时间
- **角色区分**: 用户消息和 AI 消息采用不同的视觉样式
- **附件显示**: 在消息中显示上传的图片附件

#### 2.1.3 流式响应 ✅

- **实时更新**: AI 回复内容实时流式显示，无需等待完整响应
- **流畅体验**: 流式响应提供更流畅的用户体验
- **状态管理**: 流式响应期间正确管理消息状态

### 2.2 会话管理

#### 2.2.1 会话操作 ✅

- **创建会话**: 支持创建新的对话会话
- **会话列表**: 侧边栏显示所有会话列表，按更新时间排序
- **切换会话**: 点击会话快速切换当前对话
- **删除会话**: 支持删除不需要的会话（同时删除关联的消息和附件）
- **会话标题**: 根据第一条用户消息自动生成会话标题，支持手动修改

#### 2.2.2 会话持久化 ✅

- **数据保存**: 所有会话数据自动保存到本地数据库
- **历史记录**: 应用重启后自动加载历史会话
- **消息历史**: 切换会话时自动加载该会话的所有历史消息

### 2.3 AI 模型管理

#### 2.3.1 模型配置 ✅

- **多模型支持**: 支持配置多个 AI 模型，每个模型独立配置
- **模型类型**: 支持 OpenAI、Anthropic、Custom 三种类型
- **配置项**:
  - API Key（必填）
  - Base URL（可选，支持自定义 API 地址）
  - Model 名称（必填）
  - Temperature（可选，控制回复随机性）
  - Max Tokens（最大回复长度）
  - Organization ID（OpenAI 专用，可选）

#### 2.3.2 模型管理 ✅

- **添加模型**: 通过对话框添加新的 AI 模型配置
- **编辑模型**: 支持编辑现有模型配置（API Key 留空则不修改）
- **删除模型**: 支持删除不需要的模型配置
- **默认模型**: 支持设置默认使用的模型
- **模型切换**: 在聊天界面可以快速切换使用的模型

#### 2.3.3 模型提供商支持

- **OpenAI** ✅: 完整支持
  - 支持 Responses API（GPT 系列、O1 系列）
  - 支持 Chat Completions API（兼容模型）
  - 自动判断使用哪个 API
  - 支持内置工具（web_search）
- **Anthropic (Claude)** ⏳: 待开发
- **Gemini** ⏳: 待开发
- **Custom** ✅: 支持自定义 API 端点

### 2.4 文件上传

#### 2.4.1 图片上传 ✅

- **文件选择**: 支持选择图片文件（jpg, jpeg, png, gif, webp）
- **文件预览**: 上传前可以预览选择的图片
- **多文件支持**: 单条消息支持最多 10 个附件
- **文件大小限制**: 单个文件最大 20MB
- **删除附件**: 支持删除已选择的附件

#### 2.4.2 文件处理 ✅

- **Base64 编码**: 文件以 Base64 格式存储
- **数据库存储**: 附件信息存储在本地数据库
- **消息关联**: 附件与消息关联，随消息一起保存
- **图片显示**: 在消息中显示上传的图片

#### 2.4.3 后续规划 ⏳

- **更多文件类型**: 支持 PDF、文档等需要文本提取的文件
- **拖拽上传**: 支持拖拽文件到输入框上传
- **剪贴板粘贴**: 支持从剪贴板直接粘贴图片

### 2.5 工具调用

#### 2.5.1 内置工具支持 ✅

- **Web Search**: 支持 OpenAI 内置的 web_search 工具
  - 自动启用（OpenAI 官方模型默认启用）
  - 实时显示搜索状态
  - 显示搜索查询内容

#### 2.5.2 工具调用显示 ✅

- **状态显示**: 实时显示工具调用状态
  - in_progress: 准备中
  - searching: 搜索中
  - completed: 已完成
  - failed: 失败
- **工具类型**: 显示工具类型（web_search、file_search 等）
- **查询内容**: 显示工具调用的查询内容
- **视觉反馈**: 不同状态使用不同的图标和颜色

#### 2.5.3 后续规划 ⏳

- **File Search**: 支持 OpenAI 内置的 file_search 工具
- **自定义工具**: 支持客户端自定义 tools
- **工具配置**: 支持配置哪些工具可用

### 2.6 设置和配置

#### 2.6.1 应用设置 ✅

- **主题设置**: 支持浅色、深色、跟随系统三种主题模式
- **设置持久化**: 所有设置自动保存到本地数据库

#### 2.6.2 模型管理界面 ✅

- **模型列表**: 设置页面显示所有已配置的模型
- **添加模型**: 通过对话框添加新模型
- **编辑模型**: 点击模型可以编辑配置
- **删除模型**: 支持删除模型（带确认提示）
- **设置默认**: 支持设置默认模型

## 三、用户体验

### 3.1 界面设计 ✅

- **现代化 UI**: 基于 shadcn/ui 组件库，提供现代化的界面设计
- **响应式布局**: 适配不同窗口大小
- **侧边栏**: 可折叠的侧边栏，显示会话列表和设置入口
- **空状态**: 无消息时显示友好的空状态提示
- **加载状态**: 显示消息加载和发送状态

### 3.2 交互体验 ✅

- **快捷键**: Enter 发送消息，Shift+Enter 换行
- **自动滚动**: 新消息自动滚动到底部
- **实时反馈**: 流式响应提供实时反馈
- **错误提示**: 友好的错误提示信息

### 3.3 已知问题 ⚠️

- **滚动问题**: 聊天界面滚动到底部功能不稳定（待优化）

## 四、数据管理

### 4.1 数据持久化 ✅

- **本地数据库**: 使用 SQLite 数据库存储所有数据
- **自动保存**: 会话、消息、附件、配置等数据自动保存
- **数据恢复**: 应用重启后自动恢复所有数据

### 4.2 数据安全 ✅

- **API Key 保护**: API Key 存储在数据库，不暴露到前端
- **本地存储**: 所有数据存储在本地，不上传到服务器
- **单实例锁**: 防止多个应用实例同时运行导致数据冲突

## 八、技术实现概览

### 8.1 技术栈

- **框架**: Electron + React 19 + TypeScript
- **状态管理**: Zustand
- **UI 组件**: shadcn/ui + Tailwind CSS v4
- **数据库**: Prisma ORM + SQLite
- **AI SDK**: OpenAI SDK v6

### 8.2 架构特点

- **分层架构**: Renderer 层、IPC 层、Main 层、Provider 层、Repository 层
- **设计模式**: 策略模式、工厂模式、适配器模式、仓储模式
- **类型安全**: 完整的 TypeScript 类型定义
- **错误处理**: 完善的错误处理和日志记录
